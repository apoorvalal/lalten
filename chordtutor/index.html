ChordTutor

2 octaves of keys. Pick a root + chord quality. Highlights chord tones and plays via WebAudio, and optionally sends MIDI note-on/off if you select a MIDI output.

35 ms between chord tones
0.25
Audio: idle MIDI: not connected
Sequence (up to 4 chord changes)
Each slot uses its own root/quality/inversion. Uses the same strum and gain.
1100 ms per chord
If your browser supports WebMIDI (Chrome/Edge) you can route chord notes to a synth. We still play locally via WebAudio.
Tip: click keys to audition single notes.
This is a deliberately simple “basis”: chord tones are built from interval sets (semitones) + optional extensions. Some names overlap in practice; this is intended as a tutor/toy, not a full jazz theory engine.
If you want: add a “scale mode” view (Ionian/Dorian/etc) or voicing presets (drop-2, quartal).
